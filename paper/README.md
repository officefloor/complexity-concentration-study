# The paper

*Complexity concentration as a god-class and god-method detector. A pre-registered test of a
scale-free outlier rule against tool definitions and human labels.*

## What is here

| File | Purpose |
|---|---|
| `main.tex` | The paper. Self contained: no `.bib`, the bibliography is a `thebibliography` environment. Every number is a macro from `generated/numbers.tex`, every table an `\input` of `generated/tab_*.tex`. |
| `generated/` | The tables and the number macros, written by `scripts/tables.py`. **Tracked**, so the paper builds on a fresh clone with no results; regenerated by `./regenerate.sh`. |
| `figures/` | The figures (PDF), written by `scripts/figures.py`. Tracked, for the same reason. |
| `scripts/` | The paper's analysis and drawing scripts; each one's docstring says what it reads and writes. `scripts/common.py` imports the harness package from the repository root so the paper computes with the harness's own tested statistics and rules. |
| `data/` | Intermediate reductions of the runs' per-unit sidecars (`main.json`, `mlcq.json`) and the paper's read-outs (`human.json`, `agreement.json`, `transfer.json`, `false_positives.json`, the reading sample and readings, logs). Git-ignored; regenerated from `../results/`. |
| `anc-README.md` | The ancillary README packed into the arXiv bundle as `anc/README.md`: the key to every repository, file and command. **Every GitHub link lives here**, not in the paper. |
| `regeneration.txt` | The map from every table, figure and inline number to the command that produces it; packed as `anc/REGENERATION.txt`. |
| `requirements.txt`, `setup.sh` | The figure toolchain (matplotlib, pinned) and a TeX check. |
| `regenerate.sh` | Extract, check, read out, tabulate, draw. |
| `build.sh` | `pdflatex` twice, `abstract.txt` (git-ignored) and `arxiv.tar.gz` (git-ignored) with the ancillary data under `anc/`. |

## Build

    ./setup.sh        # once: paper/.venv with matplotlib; checks pdflatex and its packages
    ./build.sh        # main.pdf, abstract.txt, arxiv.tar.gz

The build needs only `main.tex`, `generated/` and `figures/`, so it works on a clone with no
results and no Python. `./build.sh` packs the ancillary data from `../results/` and `../sample/`
when they are present and warns about what is missing.

## Regenerate the numbers

    ./regenerate.sh                  # from ../results/2026-10-19 and ../results/mlcq
    ./regenerate.sh --skip-extract   # reuse data/*.json; re-run the read-outs, tables, figures

`regenerate.sh` streams the two per-unit sidecars (half a gigabyte and a gigabyte) into compact
JSON under `data/`, checks the main-run reduction against the harness's own `analysis.json`
(`scripts/check_extract.py`, which must print `ALL OK`), computes the human-label read-out and
the agreement comparison, and writes every table, macro and figure. The two results directories
can be pointed elsewhere with `--main` and `--mlcq` (or `CCS_MAIN_RESULTS`,
`CCS_MLCQ_RESULTS`).

## Why the paper has its own analysis scripts

The harness's `analyse` is the analysis of record for every tool definition. The human-label
read-out and the exploratory agreement are computed here, and the paper says so (Section 6):

- the harness writes its definition registry before the first repository is measured and reads
  its secondaries from it, and the MLCQ run's registry holds no human definition, so its
  `analysis.json` carries no human read-out; `scripts/human_readout.py` performs the planned
  read-out with the harness's statistics and the plan's constants, on the reviewed units
  `scripts/extract_mlcq.py` reduces from the sidecar using the end-of-run registry;
- `scripts/agreement.py` computes the exploratory agreement on the same reviewed units; the
  harness's step 5a output, scored over every Java class, is superseded by it;
- `scripts/transfer.py` reads the explore-tuned cutoff of each population on the other's
  confirm half (the comparison the plan never made), and the relative cut tuned on each
  population against that population's tuned cutoff on the plan's three arms (tuned against
  tuned, the comparison that separates the standardised axis from the constant 3.5), from the
  per-unit distributions the two extractors keep (`dist` in `main.json`, `pmd_dist` in
  `mlcq.json`);
- `scripts/false_positives.py` characterises every extra flag of the relative rule, draws the
  blinded reading sample and merges the readings; `scripts/fp_reading.py` prepares the
  author's reading and runs the model readers as blind `claude -p` sessions. `readings/` holds every reader's decisions, the one
  input no script reproduces, and is committed.

The read-outs these scripts add beyond the plan were introduced after drafts were reviewed, and the paper labels each exploratory (Section 6).

`scripts/check_extract.py` shows the paper's reduction reproduces the harness's numbers on the
main run to nine decimals, so the human read-out rests on the same code path.

## Publishing

arXiv primary class `cs.SE`. Reserve the Zenodo DOI and set `\thedoi` in `main.tex` before
submitting; `build.sh` prints the abstract's character count against arXiv's limit.
